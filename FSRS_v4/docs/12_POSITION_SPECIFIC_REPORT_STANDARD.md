# 12 — Position-Specific Report Standard

Core Layout sabittir:
- kimlik ve durum
- veri güvenilirliği
- güncel sezon
- trend
- karar özeti

Değişken modüller position engine tarafından seçilir.

## GK
Kurtarış haritası, PSxG, cross claim, sweep, distribution.

## CB
Duel map, aerial zones, progression lanes, recovery defense.

## FB
Overlap/underlap, crossing zones, final-third entries, recovery.

## DM
Ball recovery zones, passing lanes, pressure resistance, rest defense.

## CM
Progression, circulation, box-to-box coverage, creation.

## AM
Pocket receiving, through balls, chance creation, box entries.

## WINGER
Wide/half-space usage, dribble map, shot map, crossing, transition.

## ST
Box movement, shot zones, run types, aerial and link play.
