# 07 — Publication and QA Gates

## BLOCKED
- identity belirsiz
- kritik sezon kapsamı belirsiz
- veri freshness başarısız
- kritik conflict çözümsüz
- LLM schema invalid
- kanıtsız kritik iddia
- final report birden çok kaynaktan doğrudan besleniyor

## PUBLISH_WITH_WARNINGS
- bazı isteğe bağlı metrikler eksik
- bazı alanlar single source
- genç oyuncu senior örneklemi sınırlı
- potential güveni orta/düşük

## VERIFIED
- zorunlu alanlar tamam
- kritik conflict yok
- freshness yeterli
- deterministic checks geçti
- LLM evidence binding geçti
- final report schema valid

## QA
Her release:
- parser fixture
- formula regression
- benchmark reproducibility
- youth penalty
- LLM prohibited claims
- final report snapshot
testlerini geçmelidir.
