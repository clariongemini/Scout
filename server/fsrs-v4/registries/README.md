# Metric Registry

FSRS_v4 Metric Semantic Registry - Her metrik tanımı, birimi ve kapsamı burada tanımlanır.

## Kullanım
- `metric_registry.json`: Tüm metrik tanımları
- `source_registry.json`: Kaynak sağlayıcı tanımları

## FSRS_v4 Standardı
Her metrik observation bu registry'deki tanımlarla eşleşmelidir.
